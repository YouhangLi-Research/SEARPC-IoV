# Scientific artifact

This directory contains the scientific implementation and frozen experiment records used by the SEARPC manuscript.

- `code/`: mechanism, adapter, participation, sensitivity, and process-prototype runners.
- `baselines/`: independent implementations or adapters for published methods.
- `protocols/`: pre-specified experiment and provenance records.
- `results/`: deterministic risk streams, block-level traces, inference outputs, and manifests.
- `tests/`: authority, replay, registry, projection, and external-adapter checks.

Scientific modules are organized by evidence authorization, participation control, and baseline purpose. Use the repository-level `run.py` commands for execution.
